Vocal Pitch Recorder

Measures the average fundamental frequency of successive 4-second vocalizations (12-TET, A4 = 440 Hz).

Microphone permission

  1. Click Start acquisition. Your browser will ask to use the microphone; choose Allow.
  2. If you blocked it earlier, click the lock / camera icon left of the address bar, set Microphone → Allow, then reload the page.
  3. The page must be opened via https:// or http://localhost; microphones are unavailable on plain http or many file:// pages.
  4. On macOS/Windows, also check that the OS privacy settings allow the browser to use the microphone.
  • Sing or hum one steady note per window. A short pause precedes each window.
  • Say "finish" or "stop acquisition" to end (Chrome/Edge/Safari), or press Stop.
